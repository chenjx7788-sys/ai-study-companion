# AI 伴学助手 · 使用说明

> 版本对齐：**v0.1.2（2026-09-09）**。完整图文说明以客户端内置「使用帮助」页为准；按版本更新见项目根 `CHANGELOG.md`。本文件供仓库内快速参考。

## 快速开始

1. **双击 `AIStudyCompanion.exe`** 启动（onedir 免安装版，首次启动自动就位内置向量模型，约 7 秒）
2. 应用以独立窗口打开（若未弹出，手动访问 http://127.0.0.1:8000）
3. 进入左侧「管理中心 → 大模型配置」，添加你的 LLM API Key
4. 回到「材料库」上传 / 引用本地资料 / 新增文档，即可开始使用

## 配置 API Key

- 推荐 DeepSeek：前往 https://platform.deepseek.com 注册，创建 API Key
- 「管理中心 → 大模型配置 → 添加模型」填写：
  - 名称：随意（如 DeepSeek）
  - Base URL：`https://api.deepseek.com`
  - API Key：你的 `sk-...`
  - 模型名：`deepseek-chat`
- 可添加多个厂商模型并存；在「总结模型」「问答模型」下拉分别指定，问答页可一键切换

## 数据与隐私

- 所有数据（资料、笔记、向量索引）**只保存在本机**，不上传云端
- 数据目录：Windows `C:\Users\你的用户名\.ai-study-companion`
- **引用模式**只记录源文件路径、不复制文件；删除材料不会删除你的原文件
- 备份：管理中心 → 存储管理 → 一键备份 / 从备份恢复（另有每日自动备份）

## 常见问题

- **音视频转写慢？** 首次转写需下载语音模型（默认 small 约 464MB，可切 base 约 139MB），管理中心可提前下载并查看进度；转写为 CPU 本地推理，速度约音频时长 1/3，长视频请耐心等待
- **扫描版 PDF / 图片怎么读？** 本地 OCR 自动识别（无需联网），识别文字可像普通文本一样划线、总结、出题
- **关闭后数据会丢吗？** 不会，数据持久保存在本机用户目录
- **换了电脑？** 用「一键备份」导出，新电脑「从备份恢复」
- **如何更新版本？** 到官网下载区或 GitHub Releases 下载新版本，解压后替换即可（原数据在用户目录不受影响）

## 退出

关闭应用窗口即可；若需完全退出，结束 `AIStudyCompanion.exe` 进程。
