# AI 伴学助手 · 使用说明

## 快速开始

1. **双击 `AIStudyCompanion.exe`** 启动（首次启动会自动预置向量模型，稍等几秒）
2. 应用会以独立窗口打开（若未弹出，手动访问 http://127.0.0.1:8000）
3. 进入左侧「管理中心」→「LLM 模型」→「添加模型」，填入你的 API Key
4. 回到「材料库」上传学习材料，即可开始使用

## 配置 API Key

- 推荐使用 DeepSeek：前往 https://platform.deepseek.com 注册，创建 API Key
- 在「管理中心 → LLM 模型」点「添加模型」，填写：
  - 名称：随意（如 DeepSeek）
  - Base URL：`https://api.deepseek.com`
  - API Key：你的 `sk-...`
  - 模型名：`deepseek-chat`
- 保存后，在「总结模型」「问答模型」下拉里选中它

## 功能一览

| 模块 | 能力 |
|---|---|
| 材料库 | 上传 PDF/PPT/Word/音视频，自动解析入库 |
| 学习页 | 阅读 + 划线高亮 + AI 解读 + 笔记 |
| AI 问答 | 针对你的知识库提问，引用溯源 |
| 复习巩固 | AI 出题 + 间隔复习对抗遗忘 |

## 数据与隐私

- 所有数据（资料、笔记、索引）**只保存在本机**，不上传云端
- 数据目录：Windows `C:\Users\你的用户名\.ai-study-companion`
- 备份：管理中心 → 存储管理 → 一键备份

## 常见问题

- **音视频转写慢？** 首次转写需下载语音模型（约 145MB），之后会加速
- **关闭后数据会丢吗？** 不会，数据持久保存在本机用户目录
- **换了电脑？** 用「一键备份」导出，新电脑「从备份恢复」

## 退出

关闭应用窗口即可；若需完全退出，结束 `AIStudyCompanion.exe` 进程。
